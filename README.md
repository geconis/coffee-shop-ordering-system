# Coffee Shop Ordering System

Вебсистема онлайн-замовлень у кав’ярні.

## Опис

Проєкт призначений для перегляду меню кав’ярні та формування замовлення за допомогою кошика.

## Основні можливості

- перегляд меню;
- перегляд фотографій товарів;
- перегляд цін;
- перегляд категорій меню;
- додавання товарів до кошика;
- редагування вмісту кошика;
- адміністративна панель;
- редагування меню;
- зміна цін.
